noxbuild.cc
===========

This repository contains the public website and documentation for the Nox build system.

Nox is a Rust-based build and task system that reads project state from `nox.build`,
optionally uses `noxfile` for automation, and keeps dependency-aware build execution
language-neutral across native and managed toolchains.

The site documents the core concepts, command-line workflow, toolchain behavior,
installation steps, and project configuration for working with Nox.
